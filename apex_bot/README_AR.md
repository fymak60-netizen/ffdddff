# ⚡ APEX FOREX BOT — بوت فوركس تلقائي ببايثون + MetaTrader 5

بوت تداول آلي كامل يربط بايثون بمنصة **MetaTrader 5** مباشرة، ويحمل داخله **نسخة بايثون مطابقة لمحرك APEX LIQUIDITY ENGINE** (مفاهيم Smart Money / ICT الموجودة في مؤشر الباي `pine/apex_liquidity_engine.pine`)، مع **3 استراتيجيات إضافية** ومحرك **اختبار تاريخي** وإدارة مخاطر تلقائية.

> **أنت تختار الزوج والاستراتيجية والفريم — والبوت ينفذ تلقائياً:** يحلل كل شمعة جديدة، يفتح الصفقة بحجم محسوب من نسبة مخاطرتك، يضع الوقف والهدف، وينقل الوقف للتعادل بعد الربح.

## 🧠 محرك APEX SMC (الخوارزمية الأساسية)

لا يستخدم RSI/MACD — بل **7 محركات مؤسساتية** مطابقة لمؤشر الباي، وتُقيَّم الإشارة من **0 إلى 5** ولا تُنفذ إلا باجتماع عدة شروط:

| # | المحرك | الفكرة |
|---|--------|--------|
| 1 | **Market Structure** | BOS (كسر هيكل) و CHoCH (تغير شخصية) عبر قمم/قيعان ديناميكية |
| 2 | **Liquidity Sweep** | فتيل يخترق قمة/قاعاً ثم يغلق داخلها = اصطياد ستوبات المؤسسات |
| 3 | **Equal Highs/Lows** | رصد مغناطيس السيولة |
| 4 | **Order Blocks** | آخر شمعة معاكسة قبل اندفاع > 0.9×ATR، مع حذف تلقائي بعد الكسر |
| 5 | **Fair Value Gap** | فجوات عدم التوازن (3 شموع) تُحذف عند الامتلاء |
| 6 | **Delta Volume** | تقدير ضغط المشترين/البائعين داخل الشمعة |
| 7 | **Kill Zones + Premium/Discount** | توقيت لندن/نيويورك + الشراء بالخصم والبيع بالبريميوم |

**قاعدة الدخول:** `الدرجة ≥ min_score` (افتراضي 3) **و** اتجاه واحد يتفوق على الآخر **و** فترة تبريد بين الإشارات.
**الخروج:** وقف = `1.2×ATR` | هدف = `2R` (قابل للتعديل) + نقل الوقف للتعادل بعد `+1R`.

## 🚀 طرق التشغيل

### الطريقة 1 — القائمة التفاعلية (الأسهل)

```bash
python run.py
```

ستظهر قوائم عربية مرتبة: **اختر الزوج ← الاستراتيجية ← الفريم ← الحساسية ← وضع التشغيل ← المخاطرة**.

### الطريقة 2 — أوامر مباشرة (للتشغيل الأوتوماتيكي)

```bash
# 🔴 تشغيل البوت تلقائياً على EURUSD (تأكد أنه حساب ديمو!)
python run.py live --symbol EURUSD --strategy smc --timeframe M15 --risk 1

# 🧪 وضع ورقي: بيانات حية من MT5 لكن التنفيذ محاكى (صفر مخاطرة)
python run.py live --symbol XAUUSD --strategy smc --paper

# 🔬 اختبار تاريخي على 5000 شمعة من MT5
python run.py backtest --symbol GBPJPY --strategy smc --timeframe H1 --bars 5000

# 🔬 اختبار من ملف CSV (بدون MT5 — يعمل على أي نظام)
python run.py backtest --csv data.csv --symbol EURUSD --strategy ema

# 💾 مع حفظ تفاصيل كل صفقة
python run.py backtest --symbol EURUSD --save-trades trades.csv

# 🔐 حساب محدد بدل المنصة المفتوحة
python run.py live --symbol EURUSD --login 12345678 --password "كلمةالمرور" --server "Broker-Demo"
```

### الاستراتيجية بدل smc

| الأمر | الوصف |
|-------|-------|
| `--strategy smc` | **APEX SMC** — المحرك المؤسساتي الكامل (موصى به) |
| `--strategy ema` | تقاطع EMA 9/21 مع فلتر اتجاه EMA200 |
| `--strategy rsi` | انعكاس RSI من التشبع مع الاتجاه العام |
| `--strategy macd` | تقاطع MACD + زخم + فلتر اتجاه |

```
[14:30:05] 🕯️ شمعة جديدة | السعر: 1.08542 | الهيكل: ▲ | درجة: شراء 4/5 — بيع 1/5 | ATR: 0.00071
        العوامل: BOS↑ كسر هيكل صاعد, لمس أوردر بلوك شرائي OB+, ضغط دلتا شرائي, Kill Zone + منطقة خصم
        ┌────────────── صفقة جديدة ──────────────
        │ 🟢 شراء BUY  EURUSD  |  لوت: 0.85
        │ الدخول : 1.08545 | الوقف: 1.08460 | الهدف: 1.08715 (+2R)
        │ المخاطرة: 1.0% من 10000.00$
        └────────────────────────────────────────
```

## 🛡️ إدارة المخاطر (تلقائية بالكامل)

- **حجم اللوت** = `(الرصيد × نسبة المخاطرة) ÷ خسارة الوقف للوت الواحد` — تُحسب من `tick_value/tick_size` الحقيقيين للوسيط.
- **الوقف** = `1.2 × ATR` | **الهدف** = `2R` (ضعف مسافة الوقف).
- **وقف التعادل**: بعد ربح بمقدار مسافة الوقف، يُنقل SL لنقطة الدخول + هامش بسيط.
- **حد الصفقات**: صفقة واحدة مفتوحة افتراضياً (`max_positions`).

> ⚠️ **قاعدة ذهبية**: لا ترفع `risk` فوق 1-2%. حتى أقوى الخوارزميات تمر بسلاسل خسائر.

## 🔬 تقرير الاختبار التاريخي

```
┌────────────────────── 📊 نتيجة الاختبار ──────────────────────┐
  عدد الصفقات / نسبة الفوز / عامل الربح PF
  صافي الربح / العائد / أقصى تراجع DD / التوقع لكل صفقة
└─────────────────────────────────────────────────────────────┘
```
- **PF > 1.5** و **DD < 20%** = استراتيجية قابلة للتشغيل.
- الدخول واقعي (على فتح الشمعة التالية للإشارة) والخروج محافظ (الوقف أولاً عند التعارض).

## ⚙️ أهم إعدادات `config.py`

| الإعداد | الافتراضي | المعنى |
|---------|-----------|--------|
| `symbol` | EURUSD | الزوج (كما يظهر في Market Watch) |
| `timeframe` | M15 | M1 M5 M15 M30 H1 H4 D1 |
| `strategy` | smc | smc / ema / rsi / macd |
| `min_score` | 3 | ارفعه لـ 4-5 لإشارات أندر وأقوى |
| `risk_percent` | 1.0 | مخاطرة الصفقة % من الرصيد |
| `atr_sl_mult` | 1.2 | مسافة الوقف × ATR |
| `rr1` | 2.0 | الهدف (مضاعف مسافة الوقف) |
| `swing_len` | 8 | حساسية الهيكل (5 للسكالب، 12 للسوينق) |
| `use_killzones` | True | اسمح فقط بجلسات لندن/نيويورك |
| `trailing_breakeven` | True | وقف التعادل بعد +1R |
| `lookback` | 400 | عدد الشموع المحللة كل دورة |
| `poll_seconds` | 5 | فترة الفحص بالثواني |

**إعدادات مقترحة حسب الفريم** (كما في دليل المؤشر):

| الفريم | swing_len | min_score | Kill Zones |
|--------|-----------|-----------|------------|
| M1–M5 سكالب | 5 | 3 | مفعّل |
| M15–H1 يومي | 8 | 4 | مفعّل |
| H4–D1 سوينق | 12 | 3 | معطّل (`--timeframe H4` وعدّل config) |

## ❓ أسئلة شائعة

**• الرمز غير موجود!** بعض الوسطاء يضيفون لاحقة: `EURUSD.m`, `EURUSDm`, `EURUSD.raw`. افتح Market Watch وانقل الاسم بدقة.

**• "فشل الاتصال بمنصة MT5"** → تأكد أن المنصة مفتوحة، ومسجَّل دخول بحساب، وAlgo Trading + Python integration مفعّلان (الأقسام أعلاه).

**• لا صفقات تظهر** → خفّض `min_score` إلى 2، أو غيّر الفريم، أو عطّل `use_killzones` (خارج جلسات لندن/نيويورك لا إشارات).

**• أريد إيقاف البوت** → `Ctrl+C` (يُغلق الاتصال بأمان ويترك صفقاتك المفتوحة بوقفها وهدفها على المنصة).

## ⚠️ إخلاء مسؤولية — اقرأها بجدية

هذه **أداة برمجية تحليلية وتنفيذية وليست نصيحة مالية ولا ضمان ربح**. لا توجد خوارزمية في العالم تربح دائماً — الأسواق تحمل مخاطر خسارة كامل رأس المال. محرك SMC هنا يطبق مفاهيم مؤسساتية قوية ومنطقاً صارماً لتقييم الإشارات وإدارة المخاطر، لكن:

1. **اختبر تاريخياً** (`backtest`) على بيانات حقيقية لسنوات.
2. **شغّل على ديمو** أسابيع قبل أي مال حقيقي.
3. **لا تخاطر أبداً بأكثر من 1-2%** لكل صفقة ولا بمال لا تتحمل خسارته.
4. راقب البوت أثناء الأخبار عالية التأثير (NFP، FOMC...).
