# APEX LIQUIDITY ENGINE ⚡ — مؤشر السيولة المؤسساتية

مؤشر Pine Script v5 مبني على **مفاهيم السيولة الذكية (Smart Money / ICT)** — لا يحتوي على RSI/MACD/Stochastic ولا أي مؤشر تقليدي متأخر.

## المفاهيم الداخلية (7 محركات)

| # | المحرك | الفكرة |
|---|--------|--------|
| 1 | **Market Structure** | BOS (كسر هيكل) و CHoCH (تغير شخصية) عبر Pivots ديناميكية |
| 2 | **Liquidity Sweep** | اصطياد ستوبات: فتيل يخترق قمة/قاع ثم يغلق داخلها = دخول المؤسسات |
| 3 | **Equal Highs/Lows** | مغناطيس السيولة — الأسعار المتساوية تُستهدف دائماً |
| 4 | **Order Blocks** | آخر شمعة معاكسة قبل اندفاع > 0.9×ATR، مع Mitigation تلقائي |
| 5 | **Fair Value Gap** | فجوات عدم التوازن (3 شموع) وتُحذف عند الملء |
| 6 | **Delta Volume** | تقدير ضغط الشراء/البيع داخل الشمعة (بدون بيانات Tick) |
| 7 | **Kill Zones + Premium/Discount** | توقيت لندن/نيويورك + الشراء بالخصم والبيع بالبريميوم |

## نظام التقييم (Scoring 0–5)
الإشارة لا تظهر إلا إذا اجتمعت شروط متعددة. الافتراضي `minScore = 3`.
- ارفعه إلى **4 أو 5** = إشارات نادرة جداً لكن عالية الدقة.
- خفّضه إلى **2** = إشارات أكثر للسكالبينج.

## إدارة المخاطر
وقف الخسارة = `1.2 × ATR`، الأهداف تلقائية عند `2R` و `3.5R` وتُرسم على الشارت.

## طريقة التركيب
1. TradingView → **Pine Editor**
2. الصق محتوى `apex_liquidity_engine.pine`
3. **Save** ثم **Add to chart**
