# QFlow LAB — مختبر التدفق الكمي

مؤشر TradingView (Pine Script v6) مبني على فكرة مختلفة عن كل المؤشرات
التقليدية: بدل ما يسأل «السعر رايح فين؟»، بيسأل الأول
**«هل السوق ده قابل للتنبؤ أصلًا دلوقتي؟ وهل أنا بتاجر مع الفلوس المطّلعة
ولا ضدها؟ وهل السيولة تسمح بالصفقة دي؟»**

التلات أسئلة بيتمثّلوا في تلات محاور مستقلة:

```
① الاستمرارية  ←  Hurst (Variance-Ratio متعدد الآفاق)
② الإنتروبي    ←  Permutation + Shannon Entropy
③ التدفق       ←  VPIN على «ساعة الحجم» + OFI + Kyle λ + Amihud
                    + سبريد Corwin–Schultz المُقدَّر من High/Low
```

المحاور التلاتة بيرسموا **فضاء طور** متحرك، وآلة أنظمة بتحدد:
**TREND** (تدوير مع التدفق) · **REVERT** (عكس التمدد) · **NOISE** (مفيش صفقة).
وبعدها **Meta-labeling** بيسأل «الإشارة دي تستاهل؟»، وبعدها **الحواجز الثلاثة**
(وقف / هدف / وقت) وإدارة حجم بالـ 1%.

> 🔑 **أهم قرار في المؤشر مش الشراء ولا البيع — ده قرار الـ NOISE.**
> أغلب خسائر الريتيل بتيجي من التداول في ضجيج.

## التركيب

1. افتح TradingView → Pine Editor → الصق محتوى `pine/QFL_QuantFlowLab.pine` → **Add to chart**.
2. علّقه على **XAUUSD** (أو أي أداة) على **15m**.
3. الفريم الأكبر افتراضيًا **4H** — غيّره من الإعدادات لو بتتداول فريم تاني.
4. الجلسة الافتراضية **07:00–16:30 GMT** مع حظر الرول أوفر 21:45–22:15.

**الخطة المجانية تكفي**: مفيش `request.footprint` ولا `request.security_lower_tf`
ولا ثواني. فيه 8 `alertcondition` — لو خطتك بتسمح بعدد alerts أقل، فعّل
اللي محتاجه بس (أهم اتنين: «شراء» و«بيع»).

## أرقام الدولار (تقديرية — مش باك تست)

على الافتراضات اللي اتفقنا عليها (حساب وهمي **$10,000** · مخاطرة **1%** ·
نجاح **55%** · **R:R = 1.8**):

| | |
|---|---|
| المخاطرة في الصفقة | **$100** |
| نقطة التعادل | **35.7%** نجاح |
| التوقع الصافي | **+0.50R = +$50 / صفقة** |
| 20 صفقة/شهر | **+$1,000/شهر (+10%)** ⇒ **$31,384** آخر السنة |
| الانحراف المعياري | **$139/صفقة** ⇒ شهر وحش ممكن يوصل **−$1,246** |

> ⚠ **دي حسابات على افتراضات، مش نتائج.** الشرط الصعب مش الحساب —
> الشرط الصعب هو إن النظام يحقق 55% فعلًا. الطريقة الوحيدة لمعرفة ده:
> `QFL_QuantFlowLab_Strategy.pine` في الـ **Strategy Tester** على بياناتك إنت،
> على **3 أدوات و3 فريمات مختلفة**. لو نجح على واحد بس ⇒ ده حظ.
