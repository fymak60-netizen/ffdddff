## 🚀 التركيب (دقيقتان)

1. افتح **TradingView** ← الشارت المطلوب (مثلاً `EURUSD`).
2. افتح **Pine Editor** من أسفل الشاشة.
3. امسح القالب الافتراضي، والصق كامل محتوى ملف `SMC_Institutional_Beast_PRO.pine`.
4. اضغط **Add to chart**. ✅ لا يحتاج أي مكتبات أو مؤشرات خارجية.

## 🛡️ لماذا هذا الكود لا يفشل ولا "يعيد الرسم"؟

الكود كُتب ضد أخطاء Pine v6 الـ13 الأكثر شيوعاً (راجعتُ مرجعيات الترحيل الرسمية سطراً بسطر):

1. **`bool` بلا `na`** — v6 يمنع bool ثلاثي الحالة؛ كل شروط المؤشر صارمة true/false.
2. **`plot/bgcolor/barcolor/plotshape` في Global Scope فقط** — v6 يرفضها داخل `if` (أُدرجت كلها في القسم العام).
3. **تعريفات `na` منوّعة صراحة** — `float x = na` / `int x = na` (v6 يرفض `x = na` العارية).
4. **لا قسمة صحيحة خفية** — في v6 الناتج `5/2 = 2.5`، واستُخدم `math.floor` + `int()` حيث يلزم (مراكز التسميات).
5. **`request.security` مضاد لإعادة الرسم** — كل البيانات الأعلى زمناً مزاحة بشمعة مؤكدة `[1]` مع `lookahead_on` + `gaps_off` الصريحتين.
6. **البيفوتات مؤكدة** (تُعتمد بعد اكتمال الشموع اليمنى) — لا قرارات على شموع نصف مكتملة.
7. **حدود الرسم 500** محفوظة عبر قصّ تلقائي للمصفوفات (FVG ≤ 12 لكل جهة، OB ≤ 8، تسميات ≤ 60، خطوط ≤ 30).
8. **حذف الصناديق عند التعبئة/الإبطال** — لا تسريب لعدّادات Boxes/Lines/Labels.
9. **لا انزياح فهارس أثناء الحذف** — كل حلقات إزالة العناصر من المصفوفات **عكسية** (من آخر المصفوفة إلى أولها).
10. فُحص آلياً بأداة `tools/pine_lint.py`: ✅ 0 أخطاء / 0 تحذيرات (أقواس، مسافات بادئة، Scope، أنواع).

## 🔬 ملاحظة علمية — OFI الحقيقي vs البديل داخل Pine

دفتر الأوامر اللحظي (Order Book / Level-2) **غير متاح داخل Pine Script** على الشارت العادي. لذلك يستخدم المؤشر التقدير المؤسسي القياسي **Close Location Value × Volume**:

```
delta_bar = volume × [ (close − low) − (high − close) ] / (high − low)
OFI%(20)  = Σ delta / Σ volume × 100
```

وهي نفس عائلة مؤشرات *Buy/Sell Pressure* المستخدمة في محركات المايكرو-ستركشر مثل مشروع **QuantumFlow**. من يريد OFI حقيقياً من دفتر الأوامر، فالطريق هو بوت مستقل (Python/C++) على بيانات Tick — انظر المراجع أدناه.
