# ⚡ Liquidity Hunter Pro — SMC Confluence Engine

> **فكرة خارج الصندوق:** بدل ما المؤشر يرسم لك كل الـ Order Blocks والـ FVGs ويزحم الشارت، المحرك هذا يحسب **نقاط التقاء Confluence Score من 0 إلى 100** لكل فرصة، ويرسم فقط مناطق **A و A+** (اللي نقاطها ≥ الحد اللي تختاره). كل نقطة = دليل من أدلة السيولة الحقيقية.

### 🧠 كيف يحسب النقاط؟

| الدليل | النقاط | شن معناها |
|---|---|---|
| **Sweep** | **30** | السعر كنس سيولة فوق قمة أو تحت قاع + سكر راجع داخل |
| **Displacement** | **25** | شمعة اندفاع قوية (جسم > 1.5×ATR) = دخول مؤسساتي |
| **FVG** | **20** | فجوة عدم توازن لم تتعبى = مغناطيس سعري |
| **HTF Bias** | **15** | انحياز 1H و 4H مع اتجاه الصفقة |
| **Volume** | **10** | فوليوم فوق المتوسط = تأكيد |

**المجموع = 100.** لو الفرصة جابت 60+ → يرسمها. لو أقل → يتجاهلها (فلترة ضجيج).

## ⏱️ الإعداد التلقائي للفريمات

**ما تحتاج تغير شي:**

- تفتح شارت **15 دقيقة** → الدخول 15m / الانحياز 1H / الانحياز الأعلى 4H
- تفتح شارت **1 ساعة** → الدخول 1H / الانحياز 4H / الأعلى يومي
- تفتح شارت **4 ساعات** → الدخول 4H / الانحياز يومي / الأعلى أسبوعي

تقدر تطفي الـ Auto وتختار الفريمات يدوياً من الإعدادات.

## 🎨 الأنيميشن والتصميم

- **Glow ثلاثي الطبقات:** كل منطقة عبارة عن 3 مستطيلات فوق بعض (خارجي شفاف جداً + وسطي + أساسي بحواف ملونة حسب الـ Tier)
- **نبض حي Live Pulse:** آخر منطقة تنبض (الشفافية تتغير مع `timenow`) + السهم يهتز فوق وتحت (`bobbing`)
- **Tier بألوان:** A+ برتقالي / A أزرق / B رمادي
- **FVG شفاف + Sweep بقطرة ماء 💧 + BOS/CHoCH + Premium/Discount + Kill Zones لندن/نيويورك**

## 🛡️ الاستراتيجية — إدارة المخاطر

- **الدخول:** Sweep + Displacement + Score ≥ الحد + انحياز HTF + (اختياري) Discount للشراء / Premium للبيع + Kill Zone
- **الوقف:** وراء طرف الـ Sweep + مسافة ATR
- **الهدف:** RR × المخاطرة (افتراضي 2.5)
- **حماية إضافية:** Time Stop (يطلع بعد X شموع) + Trailing اختياري

## 🚀 طريقة التركيب

1. افتح [TradingView Pine Editor](https://www.tradingview.com/pine-editor/)
2. انسخ كود الملف اللي تبيه
3. الصق → Save → Add to Chart
4. فعّل التنبيهات: `Create Alert` → اختار `LH Pro: Bullish Setup` أو `Bearish Setup`

### التنبيهات الجاهزة (6)
- إعداد صاعد / هابط
- كنس سيولة صاعد / هابط
- CHoCH صاعد / هابط
