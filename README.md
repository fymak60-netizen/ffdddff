# ⚡ ULTRA-HFT QUANT CORE V6 — بوت تداول حقيقي على MetaTrader 5

بوت تداول كامل مربوط بمكتبة **MetaTrader5** ببايثون: يعطيك إشارات حيّة، يفتح صفقات
تلقائياً، ويمنحك تحكماً يدوياً كاملاً (فتح / إغلاق / تجديد SL و TP) — مع لوحة تحكم

## 📦 المحتويات

```
config.py              بيانات الحساب + كل الإعدادات الافتراضية
run.py                 نقطة التشغيل (يفتح المتصفح تلقائياً)
core/
  ├─ mt5_bridge.py     جسر MetaTrader5 (اتصال، أسعار، أوامر، صفقات) + محاكي احتياطي
  ├─ indicators.py     مؤشرات NumPy مطابقة لسلوك Pine Script
  ├─ strategy.py       محرك الاستراتيجية: SMC + OFI + Z-Score + نظام النقاط
  ├─ trader.py         التنفيذ: حجم اللوت، TP جزئي، تعادل، تريلينج، حواجز أمان
  └─ engine.py         الحلقة الحيّة التي تربط الكل وتبث عبر WebSocket
server/app.py          FastAPI: REST + WebSocket
web/
  ├─ index.html        اللوحة
  ├─ styles.css        الثيم السايبربانك
  ├─ chart3d.js        محرك الرسم ثلاثي الأبعاد (Three.js)
  ├─ chart2d.js        محرك احتياطي 2D يعمل بدون إنترنت
  └─ app.js            منطق الواجهة والتحكم
```

## 🚀 التشغيل

### 1) على ويندوز (الوضع الحقيقي — موصى به)

```bash
pip install -r requirements.txt
python run.py
```

يفتح المتصفح على `http://127.0.0.1:8000` ويتصل بحسابك مباشرة.

**شروط الاتصال الحقيقي:**
- ويندوز + منصة **MetaTrader 5** مثبتة ومسجّل دخولها على نفس الحساب
- تفعيل: `Tools → Options → Expert Advisors → Allow Algo Trading`
- المنصة تبقى مفتوحة أثناء عمل البوت

بيانات حسابك مضبوطة مسبقاً في `config.py`:
```python
ACCOUNT_NUMBER   = 109215262
ACCOUNT_PASSWORD = "Io-x3aSm"
BROKER_SERVER    = "MetaQuotes-Demo"
```

### 2) على لينكس / ماك

مكتبة `MetaTrader5` تعمل على ويندوز فقط، لذلك يعمل النظام في **وضع المحاكي**
بنفس المنطق والواجهة بالكامل — مفيد للاختبار وضبط الإعدادات قبل الحقيقي.
الشريط العلوي يوضح الحالة دائماً: `MT5 حقيقي` أو `وضع المحاكي`.

### خيارات سطر الأوامر


## 🎛 اللوحة

### الوسط — الرسم ثلاثي الأبعاد
- شموع 3D حقيقية مع فتائل وأحجام وعمق ومنظور
- سحب بالماوس = تدوير · عجلة = تقريب · Shift+سحب = تحريك رأسي
- أزرار: دوران تلقائي · إعادة الزاوية · **3D/2D** · إظهار FVG · إظهار الحجم
- يعرض مباشرة: صناديق FVG، علامات BOS/CHoCH/OFI، خطوط EMA،
  مستويات Entry/SL/TP1/TP2، صفقاتك المفتوحة، وخط السعر الحي

### اليسار — لوحة التحكم الكاملة
| المجموعة | ما تتحكم به |
|---|---|
| 🚀 التداول الآلي | تفعيل الفتح التلقائي، نسبة المخاطرة، أقصى صفقات، لوت ثابت، TP جزئي، تعادل، تريلينج، حد خسارة/ربح يومي، فلتر سبريد |
| 🎯 محرك الإشارات | الوضع (صارم / متوازن / هجومي) + حد النقاط |
| 🧠 SMC | طول السوينغ، BOS، CHoCH، FVG وحدها الأدنى |
| ⚡ OFI | نافذة التدفق، مضاعف انفجار الحجم، طول الدلتا |
| 📐 Z-Score | النافذة، عتبة الدخول، حد الانعكاس المتطرف |
| 💰 المخاطر | ATR، SL/TP1/TP2 بمضاعفات ATR، نقطة تفعيل التعادل |
| 🌍 الجلسات | تقييد لندن/نيويورك بتوقيت UTC |

كل تغيير يُطبَّق فوراً على المحرك الحي بدون إعادة تشغيل.

### اليمين — البيانات الحيّة
- **التنفيذ اليدوي**: حجم، SL/TP بالسعر أو بمضاعف ATR، أزرار شراء/بيع، إغلاق الكل
- **الصفقات المفتوحة**: لكل صفقة زر ✏ لتجديد SL و TP وزر ✖ للإغلاق
- **الحالة الحية**: الاتجاه، Z-Score، OFI، الحجم النسبي، RSI، ADX، ATR، الجلسة
- **الإحصائيات**: تبويب محاكاة الاستراتيجية + تبويب حسابك الحقيقي (7 أيام)
- **آخر الإشارات** و**سجل النظام** بالعربي

## 🧠 كيف تُبنى الإشارة

نظام نقاط من 100 بدل شرط "الكل أو لا شيء" (كان يجعل الإشارات نادرة جداً):

| المكوّن | النقاط |
|---|---|
| CHoCH (تغيّر طابع السوق) | 26 |
| BOS (كسر هيكل) | 22 |
| Z-Score متطرف / فوق العتبة | 22 / 12 |
| تدفق أوامر OFI مؤكَّد | 20 |
| الاتجاه العام | 10 |
| RSI تشبع · ADX قوي | 8 · 8 |
| فجوة FVG نشطة قريبة | 8 |
| الدلتا التراكمية · EMA21/55 | 6 · 6 |
| ميل الانحدار الخطي | 4 |

**الأوضاع:**
- `strict` — كل الشروط الأساسية معاً (إشارات نادرة عالية الجودة)
- `balanced` — النقاط ≥ حد النقاط (افتراضي 65) ← موصى به
- `aggressive` — عتبة أقل بـ 15 نقطة

**إدارة الصفقة:** SL/TP بمضاعفات ATR ← إغلاق 50% عند TP1 ← نقل الوقف
للتعادل ← وقف متحرك بمسافة ATR حتى TP2.

## 🛡 حواجز الأمان

يتوقف الدخول تلقائياً عند:
- بلوغ حد الخسارة اليومي (افتراضي 5%) أو هدف الربح اليومي
- تجاوز أقصى عدد صفقات مفتوحة
- ارتفاع السبريد فوق الحد
- إشارة مكررة على نفس الشمعة
- **التداول الآلي يبدأ مطفأ دائماً** — لا يفتح شيئاً حتى تفعّله بنفسك

## 🔌 واجهة API

| المسار | الوظيفة |
|---|---|
| `GET /api/status` · `/api/snapshot` | الحالة واللقطة الكاملة |
| `POST /api/connect` | تغيير بيانات الحساب والاتصال |
| `GET /api/symbols` · `POST /api/market` | الرموز وتبديل الرمز/الإطار |
| `GET/POST /api/settings` | قراءة وتعديل كل الإعدادات |
| `POST /api/order` | أمر يدوي `{side, volume, sl, tp, sl_atr, tp_atr}` |
| `POST /api/modify` | تجديد SL/TP `{ticket, sl, tp}` |
| `POST /api/close` | إغلاق `{ticket}` أو `{all:true}` |
| `POST /api/autotrade/on\|off` | تشغيل/إيقاف الآلي |
| `GET /api/positions` · `/api/history` · `/api/signals` · `/api/logs` | بيانات حيّة |
| `WS /ws` | بث كامل كل ثانية |
