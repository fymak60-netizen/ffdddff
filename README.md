# ليل طويل — Layl Taweel

صفحة مزاج (mood page) عربية RTL عن الليلة المثالية: **تداول + أغنية + أرقيلة إلكترونية + ليل طويل**.

> «أحلى شي شعور لا يوصف.»

## التشغيل

صفحة ساكنة بالكامل — لا build ولا اعتماديات.

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# ثم افتح http://localhost:8080
```

## المحتوى

| ملف | الوصف |
| --- | --- |
| `index.html` | البنية: هيرو + ٤ مكوّنات + قائمة تشغيل + الأرقيلة التفاعلية + جدول الليل |
| `styles.css` | التصميم الليلي (أورورا، حبيبات فيلم، نيون، RTL كامل) |
| `script.js` | اختيار أغنية عشوائي، تغيير نكهة ولون، عدّاد نَفَس وبطارية، ساعة، وضع «ليل هادئ» |
| `assets/hero.jpg` | صورة الهيرو |

## تفاعلات

- **الأغاني**: فلتر المزاج (هادي / دافئ / على نار) + زر «اختار لي دلوقتي» يفتح بحث يوتيوب للمقطع المختار.
- **الأرقيلة**: ٤ نكهات تغيّر لون الصفحة كلها، وكل نَفَس يخرج دخانًا ويستهلك البطارية.
- **ليل هادئ**: زر في الشريط العلوي يخفف الحركة ويبرّد الألوان.
- **الوصولية**: `prefers-reduced-motion`, `aria-pressed`, `aria-live`، وتباين نصوص مقروء.

## تنبيه

المحتوى ترفيهي. التداول فيه مخاطرة، والأرقيلة الإلكترونية للبالغين فقط (٢١+/١٨+ حسب بلدك).
